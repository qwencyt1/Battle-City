# Battle-City
2д игра где игроку нужно уничтожать белые танки. Все просто, но если уничтожить определенное количество вражеских танков то игрок перейдет на следующий уровень.Также в игре есть сохранение, и меню где есть выбор между новой игрой и прошлым сохранением. Противники могут уничтожить игрока если попадут в него 5 раз.
